# Roadmap

Prioritize evidence from an operator pilot rather than adding unrelated infrastructure.

1. Validate anonymized current exports from each marketplace and each seller. Add regression fixtures for changed headers, order-line identifiers and cancellation rules.
2. Conduct a supervised factory pilot. Compare source quantities, approved instructions and actual work; measure preparation time only with documented before-and-after observations.
3. Verify target physical printers on A4, including scaling, long product names and multipage slips.
4. Obtain a code-signing certificate and test signed installer reputation, a clean Windows 10/11 matrix and upgrades from real earlier installations.
5. Add history pagination and move expensive parsing/backup work off the main process if measured workloads require it.
6. Consider seller-scoped SKU mappings and additional manually mappable identity fields after real export evidence establishes the rules.
7. Review protected external backup options with the factory. Keep local-only operation available.

Cloud accounts, subscriptions, live marketplace APIs and multi-user synchronization are outside the current scope and require a confirmed operational need.
